Build a Website — Step by Step

A friendly, interactive tutorial that guides you from a plain Notepad file to a live site on the web — hands-on, fast, and fun.

1 — Create an HTML file

Open Notepad (or your favorite editor). Start with this basic HTML structure:

<!doctype html>
<html>
  <head><meta charset="utf-8"><title>My Site</title></head>
  <body></body>
</html>

Save it as index.html. This is the page visitors will open in their browser.

Anything you want to appear on the page goes inside the section. For example:

<main>
  <h1>Hello, World!</h1>
  <p>This is a simple paragraph.</p>
</main>

<h1> creates a large heading

<p> creates a paragraph

After saving, double-click the index.html file to open it in your web browser and view yours webpage.

2 — Add JavaScript

JavaScript adds interactivity to your website. Create a new file called script.js and connect it to your HTML file by adding this line right before the closing </body> tag:

<script src="script.js"></script>

Example:

        <body>
            <h1>Welcome to my site</h1>

            <script src="script.js"></script>
         </body>

Now you can add JavaScript code inside script.js.

For example:

const greetBtn = document.getElementById('greetBtn');

greetBtn.addEventListener('click', () => {
  alert('Hello, World!');
});

When the page opens, a popup message will appear.

JavaScript can be used to respond to button clicks, change text or images on the page, fetch data from a server/backend, and update the page dynamically without reloading it, update the page dynamically without reloading it and many other things.

3 — Add CSS

CSS controls the appearance of your website.

Create a file called styles.css and link it inside the <head> section of your HTML file using:

<link rel="stylesheet" href="styles.css">

Example:

<head>    
    <meta charset="utf-8">
    <title>My Site</title>
    <link rel="stylesheet" href="styles.css">
</head>

Now you can add styles inside styles.css. For example:

body {
  font-family: Arial, sans-serif;
  background-color: #f4f7fb;
  margin: 20px;
}

h1 { 
  color: #0f1724;
}

This changes the page font, background color, spacing, and heading color.

Start with simple styling like fonts, colors, spacing and margins.

Then gradually add layout and responsive design rules so your site looks good on different screen sizes.

4 — Connect files

HTML, CSS, and JavaScript work together to build a complete website.

The browser first loads the HTML structure, then applies CSS styling, and finally runs JavaScript for interactivity.

A common setup looks like this:

<html>
  <head>
    <meta charset="utf-8">
    <title>My Site</title>

    
    <link rel="stylesheet" href="styles.css">
  </head>

  <body>
    <h1>Welcome to My Website</h1>
    <p>This is my first webpage.</p>

    
    <script src="script.js"></script>      
  </body>
</html>x
  • Always place CSS links in <head>.
  • Always place JS at the end of <body> or use defer.

You can also load JavaScript from using defer:

<script src="script.js" defer></script>

The defer attribute tells the browser to wait until the HTML finishes loading before running the script.

5 — Backend & Data

A backend handles things like user accounts, databases, and application logic. A common beginner setup uses Node.js with Express to create a web server.

For simple demos, user data can be stored in a file like users.json, although real applications usually use a database.

Basic backend features often include:

  • a /register endpoint to create accounts
  • a /login endpoint to sign users in
  • input validation to check usernames, emails, and passwords
  • sending responses back to the frontend

Example Express server:

const express = require("express");
const app = express();

app.use(express.json());

app.post("/register", (req, res) => {
  res.send("User registered");
});

app.post("/login", (req, res) => {
  res.send("User logged in");
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});

For real projects:

  • never store passwords in plain text
  • hash passwords using tools like bcrypt
  • validate and sanitize all user input
  • use a proper database instead of a JSON file for production apps
6 — git, npm, and localhost

Use npm to install dependencies and run the server locally. Use git to version your project and push it to GitHub.

Run locally: npm install then npm start. Visit http://localhost:3000 to confirm the backend is running.

7 — Deploy

Deploy by pushing your repository to GitHub and connecting it to a host such as Render, Vercel, or Netlify. These services will build and run your site for the public.

Tip: set environment variables for secrets and use a real database before going to production.
