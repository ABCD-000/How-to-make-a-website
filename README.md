How to Make a Website — Interactive Project

This folder contains a small interactive frontend and a simple Node/Express backend starter for teaching purposes.

Quick start:

1. Open the folder in your editor or Explorer: C:\Users\soura\Downloads\how to make a website
2. Frontend: open `index.html` in your browser to edit and preview live.
3. Backend:
   - Open a terminal in the folder.
   - Run `npm install` to install dependencies.
   - Run `npm start` to start the backend on `http://localhost:3000`.

Using git and GitHub:

- Initialize a repo: `git init`
- Add files: `git add .`
- Commit: `git commit -m "Initial tutorial project"`
- Create a GitHub repo and push: `git remote add origin <url>` then `git push -u origin main`

Deploy on Render (example):

- Create a new Web Service on Render and connect your GitHub repo.
- Set the start command to `npm start` and deploy.

Notes:
- The backend stores demo user data in `users.json` in this folder. This is for demonstration only — do not store production secrets in plain files.
- The frontend `Download Project ZIP` button will create a ZIP you can upload or push to GitHub.

Done.
